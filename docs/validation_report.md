### 漏斗范围与数值：已人工确认

作者已确认：此前的 19.35% / 41.26% / 56.65% 及 19.18% / 39.48% / 40.44% 属于“抖音广告全品类”，不能用于“抖音广告×耳机”的漏斗结论。文档已按下表的耳机组合数值统一更新：

| 范围/来源 | 3—6月：访问→加购 / 加购→下单 / 下单→支付 | 9月：访问→加购 / 加购→下单 / 下单→支付 |
| --- | --- | --- |
| 文件复算：抖音广告全品类 | 19.35% / 41.26% / 56.65% | 19.18% / 39.48% / 40.44% |
| 作者确认且与文件复算一致：抖音广告×耳机 | 19.69% / 43.65% / 68.88% | 20.24% / 41.27% / 42.31% |

工作表“抖音正常期3-6月”和“抖音9月”只有渠道筛选；“各渠道各品类访问-支付漏斗”设置了抖音广告及耳机筛选。全品类数值仅保留为范围对照，不用于耳机组合结论。

耳机组合的访问→加购、加购→下单、下单→支付分别变化 **+0.55、-2.38、-26.57 个百分点**，按显示到两位小数的百分比相减。确认后的结论为：抖音广告×耳机在9月的访问→加购率基本稳定并略有上升，加购→下单仅小幅下降，而下单→支付率从68.88%下降至42.31%，下降26.57个百分点。异常主要集中在下单→支付环节。此结论不证明具体支付系统故障。

本次仅修改 README、分析记录与本核验记录中的漏斗口径及相关状态提示，其他已经核验一致的数字、结论和原始文件保持不变。

“8—9月支付失败增加”已明确限定组合及对照期。该组合支付失败数为 8 月 44、9 月 31，相对正常期增加但并非逐月增加；全渠道全品类不支持同样概括。这属于必须说明的范围边界。
